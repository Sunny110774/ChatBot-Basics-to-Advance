# Bluewater Bank: payments support (fictional demo company)

Declined payment: confirm the transaction date, amount, payment method and the error message shown.

Common causes of a declined payment: insufficient funds, incorrect details, issuer restrictions, an expired or blocked card, and fraud-prevention checks. Do not state the exact cause without transaction evidence.

Payment status: a payment can be tracked with its reference number (for example PAY-1042). Payments held for a fraud-prevention check are usually released or returned within 1 working day.

Escalate persistent payment issues to support, sharing only the minimum details needed.
